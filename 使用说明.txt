=== 霖蛋 - 使用说明 ===

【第一步：获取 API 密钥（二选一）】

  推荐 → DeepSeek（国内直接用，不用翻墙）
  1. 浏览器打开 https://platform.deepseek.com
  2. 注册账号（手机号即可）
  3. 在 "API Keys" 页面，点"创建新的 API Key"
  4. 复制密钥（以 sk- 开头）
  5. 充值：支持支付宝/微信，最低充 10 块钱，能用很久

  备选 → Claude（需要翻墙/代理）
  1. 打开 https://console.anthropic.com
  2. 注册并创建 API Key

【第二步：启动霖蛋】

  方式一：本地运行（电脑）
  1. 确保电脑装了 Python（命令行输入 python --version 检查）
  2. 双击运行 启动.bat（Windows）

  方式二：部署到网上（手机也能用）
  去 https://render.com 注册免费账号，把这个文件夹上传上去即可

【第三步：开始聊天】
  1. 打开浏览器访问 http://localhost:5000
  2. 点右上角 ⚙️ 设置
  3. 粘贴你的 API 密钥，保存
  4. 开始和霖蛋聊天！

【添加到手机桌面（像 App 一样）】
  iPhone：用 Safari 打开网页 → 点底部"分享" → "添加到主屏幕"
  安卓：用 Chrome 打开网页 → 点右上角"⋮" → "添加到主屏幕"
